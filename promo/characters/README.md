# 看板キャラクター

役割: 毎回ちがう世界・時代・画風に「放り込まれる」実演役。どの場面でも同じ人に見えること自体が ULL の実演になる。
人物の共通条件: 日本人女性・20 代前半・色白の可愛い系・放り込まれると「は？」と顔に出るが、すぐ順応して誰よりも楽しむ。
画風の基本: 日本のセミリアルイラスト（3D ゲームのアバターや欧米 CG アニメ風にしない）。見た目の特徴は顔立ちと髪型のシルエットに 1 つだけ。

## こころを後から再開する手順

1. 顔だけは先に固める: この PNG と、仕上げた顔アップ（できたら `kokoro/` に置く）が正。
   Gemini で作り直すときは、この画像を添付して「この C の人物を同じ顔のまま」と頼む（チャット履歴に頼らない）。
2. ひなたと遠目で区別がつくよう、髪型のシルエットを変える（例: こころは長め）。決めたらここに書く。
3. あとはひなたと同じ流れ: 顔アップ 1 枚 → 素材づくり（Multi-Angle 等）→ LoRA → 動画。
