# 紹介動画・操作動画 絵コンテ（2026-10-01 初版）

素材はまだ無い。ホストが後でシチュエーション込みの高解像度で作り直す（STATUS「次の一手」2）。
この絵コンテは「何を作れば足りるか」を先に決めるためのもの。作り方は Remotion（紹介）＋ Playwright 録画（操作）。

**守ること**: GPU 型番・Modal・基盤モデル名を出さない（CLAUDE.md §2。LoRA Studio のベースモデル名だけは例外）。
人物は自前生成の顔だけ。料金の細かい話はしない（「やりたいことが叶う・要望で育てるサイト」）。

## 伝えたいこと（1 行）

**顔 1 枚から、同じ人がどんな場面でも動いてしゃべる。**
見る人が「同じ人だ」と一瞬で分かることが全て。看板キャラは見分けやすい特徴（髪型・髪色・服の定番など）を優先する。

## A. 縦型ショート（9:16・20〜30 秒・X / Shorts / TikTok）

最初の 2 秒で結論を見せる。テロップ中心・BGM のみ（声は動画内のセリフだけ）。

| # | 秒 | 画 | テロップ |
|---|----|----|---------|
| 1 | 0–2 | 完成動画の一番映えるカット（寄り・しゃべっている） | 「この子、元は写真 1 枚です」 |
| 2 | 2–4 | 元の顔 1 枚がドンと出る | 「1 枚だけ」 |
| 3 | 4–9 | 素材づくりの結果がグリッドで次々に埋まる（角度・ポーズ・場所・服） | 「角度も服も場所も、ぜんぶ作る」 |

## B. 横型紹介（16:9・60〜90 秒・YouTube / note 埋め込み / サイト）

A を伸ばし、各段に「何がすごいか」を 1 行ずつ足す。

1. **つかみ（0–5 秒）**: A-1 と同じ。
2. **1 枚から素材一式（5–25 秒）**: 元の顔 → 基準の全身像・真横・後ろ姿の候補から選ぶ画面 → 45 枚のグリッド。
   テロップ「横顔も後ろ姿も、手元に無くていい」。
3. **学習（25–40 秒）**: LoRA Studio の画面を早送り → 1,000 step〜final の比較。テロップ「途中の版もぜんぶ受け取れる」。
4. **動画（40–75 秒）**: 場面違いの動画を 4〜5 本。寄りの顔が崩れないカットを必ず入れる。セリフ付きを 1 本。
5. **おまけ（75–85 秒、任意）**: 動画超解像の使用前・使用後をスライダーで。
6. **締め（85–90 秒）**: 「要望で育つサイトです」＋ URL。

## C. 操作動画（16:9・機能ごとに 1〜3 分・「使い方はここ」用）

本物の画面をテスト用アカウントで Playwright 録画し、ズームとテロップを後乗せ。**素材づくりを撮る時に同時に撮る**（作業と撮影を 1 回で済ませる）。

**録画の仕組みは用意済み（2026-10-01）**: `promo/scripts/record.mjs`（人が操作 → F8 でテロップの目印）→ `Tutorial` コンポジションで
ズーム・カーソル・早送り・テロップを自動で付けて書き出す。手順は `promo/README.md`。demo で一通り書き出せることを確認済み。

1. 素材づくり: 画像を入れる → 写り方・作り方 → 基準の候補を選ぶ → シーン設定 → 最初の数枚で確認 → 残りを作る → LoRA Studio へ送る
2. LoRA Studio: 送られた素材 → 学習したい特徴の確認 → 学習の速さと料金 → 開始 → 完了画面でダウンロード
3. 動画: LoRA を使った動画の作り方（セリフの入れ方を含む）
4. （任意）Multi-Angle・動画超解像は短く 1 本ずつ
