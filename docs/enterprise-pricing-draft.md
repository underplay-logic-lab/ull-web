# 法人プラン 料金表のたたき台（2026-10-09・社内用）

BPO 経由の法人相談（没入型 5 面投影）の面談に向けた叩き台。**スタンス: 場所（ULL Studio）の提供・法人プラン・技術相談。制作実務は受けない。**
数字はヒアリング後に詰める前提の初期値。社外に出すときは原価・GPU 名の列を消した版を作る（CLAUDE.md §2）。

## 0. 前提（今の数字）
- 個人向けの最安: Studio ¥29,800 / 18,000C ＝ **¥1.66/C**（`credit_to_jpy`）。このとき原価の約 2.8 倍（`pricing-decision-sheet.md` §0）。
  → **原価 ≒ ¥0.59/C**。法人単価はこの 2 倍（¥1.2/C 前後）を下限の目安にする（起動待ち・失敗・保存・Gemini の取りこぼし分を吸収するため）。
- 価格方針: 値下げは量を約束する大口だけ（メモリ pricing-philosophy）。法人のまとめ買いはこれに当たる。

## 4. 契約条件の案
- 最低契約 3 か月・月額は前払い。エンタープライズの使用料は月末締め翌月末払い。
- NDA は先方の書式で可。ULL のワークフロー・設定・コードの権利は ULL に残る（使用許諾だけ）。
- 生成物の権利は利用者に帰属（利用規約どおり）。モデルのライセンス上の制限（地域・表示義務。例: Director の「Powered by MiniMax H3」）は利用者にも及ぶ。
- 運営者は障害対応のために生成物を見ることがある（管理画面）。気になるなら NDA に含める。

## 5. 実装が要るもの（契約が見えてから）
1. **組織機能**: 組織・メンバー・組織のクレジット残高・引き落とし先の選択（`debit_profile_credits` の組織版）・利用明細・招待／削除の画面。
   人ごとの機能の許可（顔入れ替え・Qwen 2.1 のお試し枠で作る予定）と土台を共通にする。最初の 1 社は「共有アカウント 1 つ」でも始められる。
2. **API**: キーの発行・取り消し、ジョブ投入と結果取得の口（今の Studio の API を外向けに整える）、回数制限。
3. **請求**: 月末の明細書き出し（CSV／PDF）、請求書払い。
